САМЫЕ ПОПУЛЯРНЫЕ ОНЛАЙН-ИГРЫ

Распакуйте архив целиком и откройте index.html в браузере.
Установка и интернет для просмотра сайта не требуются. Внешние ссылки на источники требуют интернет.

index.html — страница сайта
styles.css — оформление
app.js — выбор жанра и мобильное меню
assets/ — изображения и значок

Содержание сокращено по предоставленному DOCX. Список игр — подборка из проекта, а не подтверждённый текущий рейтинг.
CS:GO дополнена пояснением о Counter-Strike 2. Перспективы обозначены как возможные направления развития.
Источники иллюстраций и уточнений перечислены в SOURCES.txt и на странице.
